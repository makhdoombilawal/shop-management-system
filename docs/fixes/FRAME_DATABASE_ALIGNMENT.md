**Product.java (Main Frame):**
```java
private javax.swing.JComboBox<String> product_type;

// Initialized with categories from database
private void loadProductTypes() {
    product_type.removeAllItems();
    product_type.addItem("Select Category");
    product_type.addItem("➕ Add New Category");
    
    ProductService productService = new ProductService();
    List<String> types = productService.getAllProductTypes();
    for (String type : types) {
        product_type.addItem(type);
    }
}
```

## 📊 BACKEND-ONLY FIELDS (By Design)

Some fields are intentionally not displayed in UI because they're managed automatically:

### Timestamps (Auto-managed)
- `created_at` - Set by database on INSERT
- `updated_at` - Set by database on UPDATE
- `date_created` - Set by database on INSERT
- `transaction_date` - Set to current timestamp
- `generated_at` - Set when barcode is generated
- `sold_at` - Set when barcode status changes to 'sold'
- `last_login` - Updated on successful login
- `last_purchase_date` - Updated when customer makes purchase

### Auto-calculated Fields
- `total_purchases` - Sum of all customer transactions
- `stock_after_transaction` - Calculated by transaction service
- `quantity` - Derived from POS form inputs

### Status Fields (Programmatic)
- `is_active` (users) - Toggled by admin actions
- `status` (products) - Set to 'active' by default
- `status` (customers) - Set to 'active' by default
- `status` (barcode) - Lifecycle: available → sold/damaged
