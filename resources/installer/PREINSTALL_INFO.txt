================================================================================
DATABASE CONFIGURATION:
================================================================================

The installer will auto-detect your system and use:

1. MySQL 5.7+ or 8.0+ (if installed) - PREFERRED
   - Superior for multi-store deployments
   - Better performance with large datasets
   - Network/remote access capable
   - Requires: MySQL Host, Port, Username, Password

2. SQLite (fallback if MySQL not available)
   - Perfect for single-user deployments
   - No external database server needed
   - Database stored locally (C:\Program Files\ShopManagement\data\shopdb.db)
   - Fully functional but limited to local access

IMPORTANT NOTES:
  - If MySQL is installed: Have admin credentials ready
  - If MySQL is not installed: SQLite will be used automatically
  - Database will be initialized with default admin users
  - You can switch databases after installation via configuration files
