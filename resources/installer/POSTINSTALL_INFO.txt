================================================================================
TROUBLESHOOTING:
================================================================================

Application Won't Start:
  1. Ensure Java is installed: java -version
  2. Check system requirements (Windows 7+, 4GB RAM)
  3. Verify database connection (see logs)
  4. Reinstall database: Start Menu → Database Setup

Database Connection Error:
  IF USING MYSQL:
    1. Verify MySQL service is running
    2. Check MySQL credentials in config\application.properties
    3. Verify database name exists in MySQL
    4. Test MySQL connection: mysql -h host -u user -p password
  
  IF USING SQLITE:
    1. Ensure C:\Program Files\ShopManagement\data\ folder exists
    2. Check disk space (at least 500 MB free)
    3. Verify folder permissions (read/write access)

Barcode Scanner Not Working:
  1. Ensure scanner is powered and connected
  2. Test scanner with a regular text editor first
  3. Check scanner drivers are installed (manufacturer's website)
  4. Verify barcode format is compatible with scanner settings

Shortcuts Not Working:
  - Recreate from Start Menu → Shop Management System
  - Or right-click Start Menu → Find "Shop Management"

Performance Issues:
  1. Check disk space (free at least 1 GB)
  2. Close unnecessary programs
  3. Increase Java memory: Edit ShopManager.bat
  4. Database optimization: Tools → Database Maintenance
